# Next Landing (Animated SaaS)

Modern animated SaaS landing page built with:

- Next.js App Router
- TailwindCSS
- Framer Motion
- GSAP ScrollTrigger
- Lenis smooth scrolling

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Included

- Sticky glass navbar with fade-in
- Centered hero with staggered entrance
- Floating glass feature card with hover/floating motion
- Animated holographic SVG ribbon with subtle scroll parallax
- GSAP ScrollTrigger reveal animations for text/cards
- Feature grid with sequential reveal and hover lift
- Lenis smooth scrolling provider
- Framer Motion page transitions via `app/template.tsx`
- Responsive behavior for desktop/tablet/mobile
